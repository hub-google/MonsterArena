# Arena 造型系統
- 10 款永久收藏，50–300 G。帳號庫存記錄所有權，怪獸 skin_id 記錄穿戴，免費切換。
- 養成頁的變形鍵循環：偽裝 → 機器人 → 原有載具（第 4 階段以上）→ 偽裝。未解鎖載具仍可切換偽裝及真身；未穿戴時維持原本機器人／載具操作。暫時型態在登入期間保留，重新載入以伺服器穿戴資料恢復。
- 對戰首先播放 1.2 秒解除偽裝，戰鬥使用原始機甲；結算恢復開戰前的型態。世界王亦使用同一動畫，離開動畫中畫面時尚未送出的攻擊會取消。
- 社交廣場顯示公開穿戴皮膚，不公開額外私人資訊；倉庫顯示當前造型。PVP 適用於隔離 V2 後端，既有共用正式資料庫不額外開啟 V2。
- 購買與穿戴均由 game_action 驗證金幣及所有權，不消耗皮膚；能力與戰鬥結算不受影響。
- 測試：skin 單元測試、SQL 交易／廣場投影、Playwright 模擬已登入商城、購買、變身、結算、重載、廣場及世界王。CI 截圖供人工檢視。

- 手動戰術競技場也以開戰前造型快照播放同一解除偽裝動畫，結算復原、再戰重新解除偽裝，不改動正式經濟或排名。

## 造型素材
- 10 張確認過的原始 PNG 位於 `public/skins/`，每張 128×128、透明背景、8-bit RGBA、無半透明像素；商城與所有穿戴/戰鬥顯示共用同一素材，使用 pixelated 縮放。
- 原始十款 ID、價格、庫存與戰鬥機制維持不變。單元測試驗證尺寸及核准素材的 Git blob SHA；瀏覽器驗收逐張解碼並檢查透明度及共用顯示路徑。
