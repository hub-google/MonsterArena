# Arena 機械紀元

40 個圖鑑造型：每族 1 核心、1 初生機、2 職能 × 4 階段。128×128 原創彩色整數像素路徑，透明背景。戰鬥機以上可切換載具外觀；目前載具每職能共用輪廓。角色卡採四族單向克制，1.2 倍傷害。職能在服務端戰鬥中有獨立效果。

## 無破壞相容映射

不新增重複欄位，不刪除怪獸，也不變更舊資料的 family/type/life_stage、ID、名稱、年齡、裝備、戰績、金幣或擁有者。舊 family 1/2→疾風，4/5→鋼鐵，6/7→蒼空，3/8→星核；stage 1/2 共用核心/初生機；stage≥3 type=1 為職能 A、type=2/3 為職能 B。新核心按 1/4/7/3 等機率選族，新分化 type=1/2 等機率。舊名稱保留，預設蛋名僅在畫面依階段顯示。

主線 SQL 以 canonical functions 為準；現行共享資料庫仍是舊版 RPC，不能直接安裝依賴 arena_internal 的 V2。正式資料庫需在獨立遷移交易中保持原 RPC 的權限與其他交易規則。

## Live RPC 相容更新

共享資料庫仍運作 legacy RPC，使用一次具原始函式 MD5 守衛的遷移，不安裝 V2 專用 arena_internal。SQL 保留原授權限制。廣場舊版 p_type 0..3 意義不變，新版傳 11..14 篩選新種族。對戰雙方使用相同職能規則，種族克制是最終傷害 ×1.2，逆向與中立不額外扣傷。突擊每三回合爆發、迅捷偶數回合追加攻擊力、堡壘減傷、重砲週期破甲、狙擊穩定輸出、轟炸週期強擊、干擾週期抑制對手職能、修復週期回復生命。團戰首領沒有種族欄位，保持中立。
